# Roadmap: UNO Pop Deck Simulator — Visual/UX Polish

## Overview

This milestone transforms the look and feel of an already-working single-player card simulator from "Bootstrap-basic" into a cohesive, soft neo-brutalist identity (cream + dot pattern, thin rounded black outlines, rounded playful font, yellow brand, three functional accents). The journey goes foundation-first: establish the theme tokens and typography, then restyle the core surfaces, then the deck builder, then add the playful "big moment" effects with accessibility guards, and finally lock in correctness on mobile and refresh the docs. Throughout, the existing flip animation, audio, haptics, deck builder, persistence, and offline/installable PWA behavior are preserved.

## Phase Details

### Phase 1: Visual Foundation
**Goal**: Establish the complete soft neo-brutalist theme system (tokens, background, outline/radius language) and self-hosted typography that every later phase builds on, without breaking offline.
**Depends on**: Nothing (first phase)
**UI hint**: yes
**Requirements**: FND-01, FND-02, FND-03, FND-04, TYP-01, TYP-02, TYP-03
**Success Criteria** (what must be TRUE):
  1. The whole app renders on a cream background with a subtle dot pattern and a consistent thin rounded-outline look driven entirely by `:root` CSS variables
  2. Headings/display text use a self-hosted rounded font that still loads with the network disabled (offline), with `CACHE_NAME` bumped
  3. The palette defines a yellow brand plus Aman=green / POP!=red / UNO!=gold, and status text/counts meet WCAG AA contrast on the new surfaces
  4. Typographic hierarchy and spacing read as intentional across title, labels, counts, and status

### Phase 4: Big Moments & Motion
**Goal**: Add the playful payoff — celebratory and feedback effects plus micro-interactions — all gated by `prefers-reduced-motion`, and keep everything offline-safe.
**Depends on**: Phase 3
**UI hint**: yes
**Requirements**: FX-01, FX-02, FX-03, FX-04, A11Y-01
**Success Criteria** (what must be TRUE):
  1. Drawing UNO! fires a confetti/particle burst and drawing POP! triggers a subtle screen shake, with no runtime CDN dependency
  2. Button presses, panel open/close, and history item entrances animate smoothly using transform/opacity
  3. With the OS "Reduce Motion" setting on, confetti/shake/entrances are disabled or minimized while the game stays fully playable
  4. Any new effect asset is vendored locally, precached, and works offline (`CACHE_NAME` bumped)
